# Contributing

Thank you for your interest contributing to this project!

Here are some tips and guidelines to help you get started.

## Unit Testing

For any code changes, please run the unit tests before and after your change to ensure all tests pass and no noticeable slowdown occurs.

```
python tests/run_all.py
```

When adding a solver, include that in the `tests/problems.py` file in the appropriate list variables.

## Documentation

Keep all documentation descriptive and concise. 
- [README.md](README.md) - Quick guide to get started
- [FURTHER_DOCUMENTATION.md](FURTHER_DOCUMENTATION.md) - All options with more detail than README.
- [FAQ.md](FAQ.md) - Common questions or issues, explaining errors

## AI-Assisted Development

The use of AI and LLMs is encouraged. However, all issues and pull requests are reviewed by people. Please keep these thoughts in mind:

- **You are personally responsible for what you send.**
- **Create a short and to the point issue / solution about the problem at the top.**
